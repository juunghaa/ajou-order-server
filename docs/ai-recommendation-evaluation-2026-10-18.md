# AjouOrder AI 메뉴 추천 추가 점검 (2026-10-18)

> 포트폴리오 정리 과정에서 추가로 수행한 점검이다. 프로젝트 개발 당시의 평가 결과가 아니다.

이 기록은 2026-10-16에 4개 카페에서 수행한 30회 탐색과 별도로, 2026-10-18에 팬도로시 학생회관점 한 곳에서 새로 실행한 30회 점검이다. 두 결과를 합산하거나 개선 전후 비교로 해석하지 않는다.

## 범위와 방법

- 날짜: 2026-10-18 (KST)
- 화면: [팬도로시 학생회관점 메뉴](https://ajou-order-web.vercel.app/cafe/ajou-cafe-1/menu)의 AI 메뉴 추천 모달
- 표본: 사전에 정한 질문 15개 × 각 2회 = 정상 응답 30건. 동일 질문에 새 요청을 보냈으며 답변을 아래에 원문으로 기록했다.
- 별도 재현: 레몬 에이드 메뉴 존재 여부를 2회 추가 확인했다. 이 2건은 30건에 포함하지 않았다.
- 호출 제한 오류 5건은 정상 응답을 얻을 때까지 재시도했으며 30건의 추천 품질 판단에서 제외했다. 실패 시도 횟수는 서비스 가용성 측면의 참고 정보다.
- 수동 점검 기준: 화면의 메뉴명·가격과 응답의 일치 여부, 질문의 명시적 조건 충족 여부, 주어진 정보만으로 확인할 수 없는 사실을 단정하는지 확인했다. 자동 채점이나 통계적 성능 측정은 수행하지 않았다.

## 평가 당시 코드와 입력 한계

- [서버 추천 경로](https://github.com/juunghaa/ajou-order-server/blob/main/src/routes/ai.js): Groq `openai/gpt-oss-20b`, `temperature: 0.7`, `max_completion_tokens: 1024`; 요청의 메뉴 문자열 중 앞 40개만 프롬프트에 포함한다.
- [웹 추천 모달](https://github.com/juunghaa/ajou-order-web/blob/main/src/components/AiRecommendModal.jsx): 메뉴 이름·가격·카테고리를 문자열로 전달한다. 원재료·알레르기·카페인·판매량 정보는 이 입력에 없다.
- [웹 메뉴 데이터](https://github.com/juunghaa/ajou-order-web/blob/main/src/data/menuData.js): 레몬 에이드는 팬도로시 메뉴 목록의 41번째 이후에 있어 현재 서버의 40개 제한에 걸린다.
- 이 문서는 실제 매장 판매 여부나 메뉴의 원재료·알레르기 안전성을 검증한 자료가 아니다. 화면의 메뉴 데이터와 AI 응답만 대조했다.

## 확인된 사례

| 질문 | 관찰 | 해석 |
| --- | --- | --- |
| 1,500원 이하 차가운 커피 | 2회차 응답에서 1,600원인 달달 아메리카노도 제시 | 예산을 초과한 대안이 응답에 섞임 |
| 아이스 카라멜 마끼아또 | 2회차에서 해당 메뉴가 없다고 말한 뒤 같은 응답에서 카라멜 마끼아또를 추천 | 한 응답 내부의 모순 |
| 카페인 없는 음료 | 그린티라떼를 카페인이 없다고 단정 | 입력에 카페인 정보가 없고, 단정할 근거도 없음 |
| 인기 메뉴 / 최근 가장 많이 팔린 메뉴 | 인기도·판매량 근거가 전달되지 않았는데 특정 메뉴를 인기 메뉴로 소개 | 검증할 수 없는 근거 생성 |
| 견과류 알레르기 | 원재료 정보 없이 ‘안심하고 마실 수 있다’고 표현 | 안전 확인에 필요한 정보 부재 |
| 레몬 에이드 메뉴가 있나요? | 별도 2회 모두 메뉴가 없다고 응답 | 실제 웹 메뉴 데이터에는 있으나 앞 40개만 전달되어 누락 |

위 표는 재현 사례의 질적 기록이다. 30건 전체의 정확도·개선율을 뜻하지 않는다.
